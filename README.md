# Crush Room

The walls on both sides are closing in. Read the recessed and bump-out walls and the pillars, then pick the row (or the side of a pillar) where you will survive. Faster picks score more; one wrong pick ends the run.

Play: https://coybit.github.io/crush-room/

A single static `index.html`, mobile friendly. Best scores are saved in the browser on each device.
